# Inventory-Forecasting-for-JIT-Optimization

Project Overview
This project focuses on demand forecasting and inventory optimization using machine learning and Just-In-Time (JIT) principles.
🎯 Business Problem
Overstocking increases holding costs, while understocking leads to stockouts. Accurate demand forecasting is crucial for efficient inventory management.
🛠️ Workflow
1. Data Preprocessing
Time-based feature extraction
Handling missing values
Feature engineering
2. Model Development
Decision Tree Regressor
Random Forest Regressor
3. Future Forecast
Predicted next 6 months demand
4. Inventory Optimization
Safety Stock Calculation
Reorder Point Calculation
📌 Formula Used
Safety Stock = Z × σ × √Lead Time
Reorder Point = (Average Demand × Lead Time) + Safety Stock
📊 Results
The model generated reliable forecasts and optimized reorder strategies, reducing unnecessary inventory costs.
🚀 Conclusion
This project demonstrates the application of machine learning in supply chain and operations management.
